# ## Steps to build the project

1. Create a CMakeLists.txt file in the root directory of your project with the following content:

```cmake
cmake_minimum_required(VERSION 3.10)
project(MyProject)
add_executable(MyExecutable main.cpp)
```

2. create a build directory as this is where you now build the entire project from.

3. navigate to build dir in terminal and run the following command to generate the build files:

```bash
cmake -G Ninja  -- will generate the build files for the project using the Ninja build system.

ninja -- will build the project using the generated build files and add the executable to the build directory. (.exe)

./MyExecutable.exe -- will run the executable file generated by the build process.
```

4. Editing the code and rebuilding the project:

- After making changes to the source code, you can rebuild the project by running the following command

```bash

ninja -- will rebuild the project using the updated source code and generate a new executable file.
```
